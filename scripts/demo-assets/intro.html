StockCheck

The Open-Source Regression Testing Framework for Solana Token-2022 ScaledUiAmount Multipliers & Wallet Transfer Precision.
⚡
The Token-2022 Problem
ScaledUiAmount allows mints to scale user balances over time (stock splits, yield). Traditional wallets retain stale multipliers or round float numbers, corrupting raw transfer amounts.
🔬
Independent Auditor
StockCheck never alters wallet code. It observes what the user sees in the UI and independently verifies on-chain delta movements on a local Solana validator.
🛡️
Zero Math Regressions
Coordinates chain time-travel with virtual browser timers, catching multiplier retention, precision loss, and residual dust before mainnet deployment.
Cluster: Surfpool Local Testnet • Synthetic Mint: xSTOCK (6 Decimals) • Framework: Playwright + @solana/kit
